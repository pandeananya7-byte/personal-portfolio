# **App Name**: Ananya Pande Portfolio

## Core Features:

- Resume Display: Display experience, education, and skills in a structured and elegant format using the data supplied.
- Projects Gallery: Showcase projects with descriptions and images in an appealing gallery layout.
- Contact Form: Enable direct communication through an integrated contact form.
- Resume Download: Provide a prominent option to download the complete resume as a PDF.
- AI Style Recommender: Suggest potential style updates or simplifications to the provided text content based on the detected style.

## Style Guidelines:

- Primary color: Soft blue (#64B5F6), evoking a sense of professionalism.
- Background color: Light gray (#F0F4F7), providing a clean, uncluttered backdrop.
- Accent color: Deep navy (#1A237E), used for highlighting key elements and calls to action.
- Body and headline font: 'Inter' (sans-serif), a modern, neutral typeface for readability.
- Use clean, minimalist icons to represent different skills and sections.
- Employ a grid-based layout for a structured and organized presentation of content.
- Subtle animations (e.g., fade-ins) on scroll to enhance user experience.
